# Assets partagés

Assets fournis par le client, utilisables dans toutes les vidéos (captures de l'app, logos, photos, voix, musique,
polices…). Chaque fichier ajouté ici reçoit une ligne dans le tableau : ce que c'est, d'où il vient, ce qu'on a le droit
d'en faire. Les assets propres à une seule vidéo vont dans `video/video-N/assets/`.

Le kit de marque (logo, palette, faits) est dans `/brand/welockin/`.
